# 169. Majority Element

## Difficulty

Easy

## Topics

- Array
- Hash Table
- Sorting
- Counting

## Problem

Given an integer array `nums` of length `n`, return its majority element.

The majority element appears more than `⌊n / 2⌋` times. You may assume that a majority element always exists.

## Examples

### Example 1

```text
Input: nums = [3, 2, 3]
Output: 3
```

### Example 2

```text
Input: nums = [2, 2, 1, 1, 1, 2, 2]
Output: 2
```

## Constraints

```text
n == nums.length
1 <= n <= 50,000
-1,000,000,000 <= nums[i] <= 1,000,000,000
```

A majority element always exists.
